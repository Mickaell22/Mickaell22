## Proyectos

### En producción

**[EcuaInventario](https://github.com/Mickaell22/EcuaInventario_Backend)** — SaaS multitenancy para negocios gastronómicos: inventario, pedidos y facturación por suscripción, con un asistente IA que interpreta texto, audio y fotos de facturas. Django 5 + DRF + PostgreSQL, Flutter + Riverpod, Claude + Whisper.
<br/>[`backend`](https://github.com/Mickaell22/EcuaInventario_Backend) · [`app`](https://github.com/Mickaell22/EcuaInventario_Frontend)

**[Facturador](https://github.com/Mickaell22/Facturador_Backend)** — Sistema propio de facturación, pedidos y clientes con facturación electrónica integrada al SRI. En producción en [novamicktools.com](https://novamicktools.com). FastAPI + PostgreSQL + React + Tailwind.
<br/>[`backend`](https://github.com/Mickaell22/Facturador_Backend) · [`frontend`](https://github.com/Mickaell22/Facturador_Frontend)

**[Centro Tía Glenda](https://github.com/Mickaell22/ProjectTiaGlendaFrontend)** — Sistema de gestión clínica para un centro de terapia especial: multi-rol, multi-centro, 190+ componentes. React + MUI + Flask + PostgreSQL. Cliente real, entregado.
<br/>[`frontend`](https://github.com/Mickaell22/ProjectTiaGlendaFrontend) · [`backend`](https://github.com/Mickaell22/ProjectTiaGlendaBackend)

**[SimuladorPreguntas](https://github.com/Mickaell22/SimuladorPreguntasBackend)** — Simulador de exámenes de ingreso desplegado en la Universidad de Guayaquil: banco de preguntas, acceso por roles, medidas anticheating y exportación XML. Node.js + React + PostgreSQL + Docker.

### Herramientas propias

**[mcp-context-server](https://github.com/Mickaell22/mcp-context-server)** — Servidor MCP para Claude Code: indexa repositorios por semántica con ChromaDB y compresión DeepSeek, para que un agente consulte un repo entero en lenguaje natural sin quemar la ventana de contexto. Python + PostgreSQL.
<br/>[![Stars](https://img.shields.io/github/stars/Mickaell22/mcp-context-server?style=social)](https://github.com/Mickaell22/mcp-context-server) · [`dashboard`](https://github.com/Mickaell22/mcp-context-dashboard)

**[Respondón](https://github.com/Mickaell22/Respondon)** — App Android que detecta tus capturas de pantalla, extrae el texto con OCR local (ML Kit) y responde en una burbuja flotante con DeepSeek. Kotlin + Jetpack Compose.

**[MotoVox](https://github.com/Mickaell22/MotoVox)** — Intercomunicador para motociclistas: audio P2P en tiempo real sobre WiFi con WebRTC y RNNoise, C nativo integrado en Flutter por FFI (sin overhead de JVM).

**[QR Shield](https://github.com/Mickaell22/qr-shield)** — Detector de códigos QR maliciosos contra el quishing: extensión de Chromium y app Android sobre un motor en Python que combina Google Safe Browsing, VirusTotal y PhishTank.

**[ApplyJob](https://github.com/Mickaell22/ApplyJob)** — Automatiza postulaciones laborales: scrapea 7 portales de empleo, filtra las ofertas contra un perfil, redacta la carta de presentación con un LLM y auto-aplica en ATS (Workable, Greenhouse, GetOnBrd) con Playwright.
